# 🌐 Language Translation Tool

A simple AI-based **Language Translation Tool** built with **Python and Streamlit**.  
The application allows users to enter text, select a source language and target language, and translate the text using the **MyMemory Translation API**.

## 🚀 Features

- 🌐 Translate text between multiple languages
- 📝 Simple and user-friendly Streamlit interface
- 🔄 Source and target language selection
- ⚠️ Input validation
- 🔌 API-based translation
- ❌ Error handling for connection/API failures

## 🌍 Supported Languages

- English
- Urdu
- Arabic
- French
- German
- Spanish
- Chinese

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Language-Translation-Tool
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 🔄 How It Works

1. User enters text in the text box.
2. User selects the source language.
3. User selects the target language.
4. The application sends the text to the MyMemory Translation API.
5. The API returns the translated text.
6. The translated result is displayed in the Streamlit interface.

## 📸 Application

The application provides a simple interface for entering text, selecting languages, and viewing the translated result.
